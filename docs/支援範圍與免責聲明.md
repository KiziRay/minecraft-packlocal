# 支援範圍與免責聲明

> 版本 1.0.0｜最後更新 2026-08-10（台北）
> 本文是「哪些能翻、哪些不能翻」與免責條款的權威來源；程式內說明與 README 為摘要。

本工具把 Minecraft 模組整合包裡**能翻譯、且影響遊玩**的文字，盡量整理成**台灣用語繁體中文**，
並輸出成資源包 zip、翻譯 JAR 副本與可覆蓋檔。**原始 `mods/*.jar` 只讀、不處理圖片、不宣稱 100% 漢化。**

---

## 一、支援範圍（會處理）

### 1. 模組載入器（loader-agnostic）

| 載入器 | 支援 | 說明 |
|--------|------|------|
| Forge | ✅ | 讀 `assets/<模組>/lang/*.json` |
| NeoForge | ✅ | 同上 |
| Fabric | ✅ | 同上 |
| Quilt | ✅ | 同上 |

工具靠**語言檔路徑**運作，與載入器無關；只要文字放在標準 `assets/<ns>/lang/` 就能掃到。

### 2. 啟動器（會自動判讀整合包版本）

CurseForge、Modrinth App、Prism Launcher、MultiMC、PolyMC、ATLauncher、Minecraft 官方啟動器。

- 自動判讀來源：`minecraftinstance.json`、`mmc-pack.json`、`instance.cfg`、`instance.json`、`profile.json`、`versions/`。
- **不在清單上的啟動器**：仍可用，但請在工具的**版本選擇器**手動指定整合包的 Minecraft 版本。

### 3. Minecraft 版本

| 範圍 | 支援 | 說明 |
|------|------|------|
| 1.13 – 1.21.8 | ✅ | 單一 `pack_format` 整數制 |
| 1.21.9＋ | ✅ | 範圍制 `min_format`/`max_format` |
| 年份版 26.x（如 26.2 Chaos Cubed） | ✅ | 範圍制，未來多年不必更新工具 |
| 1.12.2 以下 | ⚠️ 有限 | 可翻文字，但輸出資源包的 `pack_format` 舊制不同，相容性不保證 |

### 4. 會翻譯的文字來源

- 模組／資源包／KubeJS 的**語言檔** `assets/<ns>/lang/*.json` → 產出 `zh_tw` 資源包 zip
- **FTB Quests** 任務／劇情（SNBT，輸出到 `config/ftbquests`）
- **FTB Quests 遊戲內匯出補充**：偵測到相容的 Forge／NeoForge 版本時，可選擇準備 FTB Quest Localizer 或 Precision Localizer，先匯出遊戲內任務文字再複查；不相容時略過，不影響一般翻譯。
- **Patchouli** 書本（`patchouli_books/`）
- **OpenLoader** 文字覆寫（`config/openloader/`）
- **KubeJS** 語言檔／資源
- **FancyMenu** 介面文字
- **資料包（loose datapacks）** 語言檔
- **ZIP datapack／resourcepack** 內的 JSON／文字顯示欄位（安全重建副本，不改原 ZIP）
- JAR 內 `data/<ns>/patchouli_books` 書本覆寫（輸出到結果 `data/`）
- JAR 內可辨識的 `assets/`／`data/` JSON、Markdown、properties 玩家文字（建立 `jar-translated` 副本）
- GuideME／自訂手冊 Markdown 的可讀行
- KubeJS `Text.of`／`Component.literal`／`text.literal` 顯示字串（只限明確白名單）
- **Origins / Apoli** 能力名稱與說明（`data/<ns>/powers|origins|origin_layers`，路徑感知，不動識別字）
- **任務／書本系統（1.0.0 新增，best-effort）**：Better Questing、HQM（HardcoreQuesting）、Heracles、Modonomicon
  的**顯示欄位**（name／title／subtitle／description／text…）；只翻顯示欄位可達的字串，結構欄位（id／type／icon…）不動。

### 5. 翻譯品質相關

- 簡體中文 → **台灣正體**（zh-Hant-TW，台灣用語）。
- 內建**官方台灣譯名術語表**（約 1945 條）＋你的自訂詞典。
- **翻譯記憶**跨整合包重用；**佔位符保護**（`%s`、`{0}`、`§c`…）＋換行守衛，修不好就退回原文，避免遊戲跳錯。
- 可合併社群／先前全翻**參考包**，AI 只補「仍是英文」的字。

## 二、不支援 / 通常蓋不到（誠實列出）

| 項目 | 狀態 | 原因 |
|------|------|------|
| 圖片／貼圖上的字 | ❌ 紅線 | 本工具不做圖片 OCR，範圍外 |
| 模組 JAR 的語言檔 | ✅ | 讀取 `assets/<模組>/lang/*.json`／`.lang`，建立翻譯副本；是否在套用前備份原檔由玩家選擇 |
| 含簽章的 JAR | ⚠️ 略過 | 重打包會讓簽章失效，工具保留原檔並記錄原因 |
| 寫死在 Java 程式碼裡的字串 | ⚠️ | JAR 複查會留下 class 文字線索，但不改寫 class 位元碼；要保證遊戲能玩，這類文字不會自動替換 |
| 寫死在 KubeJS **腳本邏輯**裡的字串 | ❌ | 不解析／執行程式碼；只處理明確白名單的顯示 API 字面值與語言檔 |
| GuideME 的 **特殊／動態 Markdown 結構** | ⚠️ 部分 | 一般可讀行會處理；複雜模板、程式碼區塊與動態內容需人工檢查 |
| 任意 KubeJS／CraftTweaker 腳本字串 | ❌ | 只處理明確顯示 API，不解析任意腳本邏輯 |
| 被壓成 **`.zip` 的資料包**內部文字 | ✅ 部分 | JSON／文字顯示欄位會安全解壓、翻譯、重建；超限或特殊格式會記錄略過原因 |
| 基岩版（Bedrock）整合包 | ❌ | 檔案格式與 Java 版不同 |
| 動態生成／執行期才組出來的文字 | ❌ | 靜態掃描看不到 |
| 世界閃退、缺模組、版本衝突、存檔損壞 | ❌ 不負責 | 與語言檔無關；本工具不修遊戲問題 |
| 機翻腔、專有名詞偶爾不一致 | ⚠️ | AI 本質限制；用術語表可改善 |
| FTB 任務輔助模組 | ⚠️ 選用 | 只下載已知相容版本；工具自己下載的檔案可清理，使用者原本安裝的檔案不會刪除 |

> 「本版未支援」= 目前沒做，未來可能加；「紅線 / 不支援」= 設計上不做。

## 六、未來規劃

### 獨立單一模組翻譯（尚未實作）

目前工具以 Minecraft 遊戲實例／整合包為輸入。未來規劃新增獨立服務，讓玩家可以直接選擇單一
`.jar` 或 `.zip` 模組，不需要建立整合包實例，掃描該模組自己的語言檔，並輸出只包含該模組
namespace 的翻譯資源包。

在功能正式完成前，請不要把單一模組直接拖進目前的整合包資料夾外使用；目前仍應透過可正常啟動的
Minecraft 實例執行翻譯流程。
