# 支援範圍與免責聲明

> 版本 1.0.9｜最後更新 2026-08-29（台北）
> 本文是「哪些能翻、哪些不能翻」與免責條款的權威來源；程式內說明與 README 為摘要。

本工具把 Minecraft 模組整合包裡能讀到、且影響遊玩的文字，盡量整理成台灣用語繁體中文。
**不處理圖片上的字、不宣稱 100% 漢化。** 原始模組檔只讀，套用前可選擇備份。

翻譯前請登入 Discord 並加入官方伺服器，方便維護、收集建議與調整工具。可選這台電腦上的本地模型、自訂 API 或 GPT。本地模型速度隨電腦而異，空間不足會擋下。自訂 API 與 GPT 的費用由你自負。

## 一、支援範圍（會處理）

### 1. 模組載入器

| 載入器 | 支援 | 說明 |
|--------|------|------|
| Forge | ✅ | 讀取模組語言檔 |
| NeoForge | ✅ | 同上 |
| Fabric | ✅ | 同上 |
| Quilt | ✅ | 同上 |

只要文字放在標準語言檔位置就能掃到。

### 2. 啟動器（會自動判讀整合包版本）

CurseForge、Modrinth App、Prism Launcher、MultiMC、PolyMC、ATLauncher、Minecraft 官方啟動器。

不在清單上的啟動器仍可用，請在工具裡手動指定 Minecraft 版本。

### 3. Minecraft 版本

| 範圍 | 支援 | 說明 |
|------|------|------|
| 1.13 – 1.21.8 | ✅ | 一般資源包格式 |
| 1.21.9＋ | ✅ | 新版資源包格式 |
| 年份版 26.x | ✅ | 例如 26.2 |
| 1.12.2 以下 | ❌ 不支援 | 工具會拒絕翻譯 |

### 4. 會翻譯的文字來源

- 模組／資源包的語言檔（產出繁中資源包）
- FTB Quests 任務／劇情
- FTB 任務遊戲內匯出補充（有相容方案時才出現；不相容就略過）
- Patchouli 書本
- OpenLoader 文字覆寫
- KubeJS 語言檔與明確寫成顯示用的字串
- FancyMenu 介面顯示文字
- 資料包與壓縮包內可辨識的顯示文字（重建副本，不改原檔）
- 書本／能力／任務系統的顯示欄位（名稱、說明、內文）；結構識別字不動
- Origins／Apoli 能力名稱與說明
- Better Questing、HQM、Heracles、Modonomicon 的顯示文字

### 5. 翻譯品質相關

- 簡體中文 → 台灣正體與常用台灣用語
- 內建官方台灣譯名術語表，加上你的自訂譯名
- 翻譯記憶跨整合包重用；格式符號保護，修不好就退回原文
- 可合併本機參考翻譯，只補還是英文的句子

## 二、不支援 / 通常蓋不到

| 項目 | 狀態 | 原因 |
|------|------|------|
| 圖片／貼圖上的字 | ❌ 紅線 | 不做圖片辨識 |
| 模組語言檔 | ✅ | 讀取後建立翻譯副本；是否備份由你選擇 |
| 含簽章、不能安全重寫的模組檔 | ⚠️ 略過 | 保留原檔並記錄原因 |
| 寫死在程式裡的字串 | ⚠️ | 不會自動改寫，避免遊戲無法啟動 |
| 寫死在腳本邏輯裡的字串 | ❌ | 只處理明確顯示用的文字 |
| 複雜或動態產生的手冊結構 | ⚠️ 部分 | 一般可讀行會處理，其餘需人工檢查 |
| 基岩版市集加密包 | ❌ | 讀不到明文；不做破解 |
| 基岩版作者明文／授權包 | 🔮 未來 | 尚未實作 |
| 遊戲執行時才組出來的文字 | ❌ | 靜態掃描看不到 |
| 世界閃退、缺模組、版本衝突、存檔損壞 | ❌ 不負責 | 與語言檔無關 |
| 機翻腔、專有名詞偶爾不一致 | ⚠️ | 用術語表可改善 |
| FTB 任務輔助模組 | ⚠️ 選用 | 只準備已知相容版本；原本安裝的檔案不會刪 |

1. **現況提供，不做任何擔保。** 不保證翻譯完整、正確或符合個人偏好，也不保證遊戲一定能啟動。
2. **不直接改寫你原本的模組檔。** 會讀取語言檔並建立翻譯副本；是否備份由你選擇。
3. **備份是可選的。** 預設會勾選套用前備份；取消後會直接套用且不能還原這次操作。請自行另外備份整合包與存檔，並在遊戲完全關閉時操作。

5. **第三方內容授權自負。** 請只散布你有權散布的內容。「Minecraft」「Mojang」等為其各自權利人所有。
6. **AI 與費用。** 翻譯前需 Discord 會籍（維護、收集建議、調整工具）。自訂 API 或 GPT 帳號的第三方費用由你自負。本地模型速度與穩定性隨這台電腦而異，空間不足會擋下；失敗時請改用自訂 API 或 GPT。
