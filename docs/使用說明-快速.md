# 怎麼用（玩家版）

把整合包文字變成**台灣繁體**，比較好玩。  
**不會弄壞模組本體**（不改 mods 裡的檔）。

---

## 開始前

- 已經用 **Prism／CurseForge／MultiMC** 等把整合包裝好，能正常開遊戲。  
- 知道實例在哪：啟動器裡對該整合包 → **開啟資料夾**（或「瀏覽本機檔案」）。  
- 想翻得比較完整：可以直接使用開發者代管 AI；也能在工具裡填入自己的 **AI 金鑰**，只存在你這台電腦。

---

## 翻譯整合包（最常用）

1. 打開「模組包翻譯工具」。  
2. **整合包資料夾** → 選剛開的那個實例資料夾（裡面通常有 `mods`）。  
3. **翻譯輸出位置** → 選任意資料夾，或按「使用啟動器建議的位置」。  
4. 確認 **Minecraft 版本**，通常會自動偵測；偵測不到再手動選。  
5. （建議）勾「補上原本沒有繁中的文字」；沒有自己的金鑰也能使用代管 AI，需要時再到進階設定填寫。  
6. 按 **開始翻譯**，看右邊進度，等它跑完（大包可能要一陣子）。  
7. **先完全關掉 Minecraft**（回到啟動器即可）。  
8. 按 **套用到遊戲**（會先備份，比較安心）。  
9. 再開遊戲：  
   - 設定 → 語言 → **繁體中文（台灣）**  
   - 設定 → 資源包 → **啟用** 工具做出來的那個包  

### 之後還能按

| 你想做什麼 | 按哪個 |
|------------|--------|
| 還有很多英文 | 輸出位置不要換，按 **補翻工作階段**（需要可用的 AI） |
| 結果怪怪的 | **修復工作階段**（不能修「一進世界就閃退」） |
| 看結果檔 | **開啟輸出** |
| 翻譯中想停下來 | 按 **停止翻譯**；已完成的部分會保留 |
| 想知道有沒有新版 | 按右上角 **檢查更新** |

---

## 字體看不清楚／方塊字

1. 切到 **「字體資源包」**。  
2. 選你的字體檔（`.ttf`／`.otf`／`.ttc`）。  
3. 選輸出位置 → **建立字體資源包**。  
4. 遊戲裡啟用這個字體包；若還怪，試試關掉「強制使用 Unicode 字型」後重開。

---

## 玩家常問

**會不會改壞模組？**  
不會改 `mods` 裡的 jar，翻譯結果另外放。

**套用失敗？**  
多半遊戲還沒關乾淨，關乾淨再按一次。

**還是有英文？**  
正常。圖片上的字、少數寫死在程式裡的字蓋不到；可再補翻一輪。

**世界閃退？**  
通常是缺模組等問題，不是翻譯能修的。

---

**最短路徑：**  
選整合包 → 選輸出 → 開始翻譯 → **關遊戲** → 套用 → 遊戲裡開繁中資源包。
