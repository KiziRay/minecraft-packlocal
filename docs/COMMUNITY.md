# 全球 Minecraft 玩家社群：在地化／漢化需求統整

> 來源綜合：FeedTheBeast Reddit、FTB Quest Localizer、MineAI/DeepSeek 類翻譯器、CFPA/I18nUpdateMod、VM 漢化組、巴哈繁中工具討論、CurseForge 繁中資源包說明、日本 CTE2 任務漢化筆記等（2026 彙整）。

## 期望（玩家要什麼）

1. **不改 .jar**：只產資源包／可覆蓋的 config，避免模組校驗與更新炸掉。
2. **任務書必翻**：FTB Quests 是整合包體驗核心，只翻物品名不夠。
3. **一鍵產出可裝**：zip 資源包 + 清楚安裝步驟；最好能一鍵套用並自動備份。
4. **繁中／簡中分開**：台灣玩家要 `zh_tw` + 台灣用語，不要整包簡中硬塞。
5. **可接社群成品**：能合併已有漢化包（CFPA／VM／CTE2 TW）當底，再補缺。
6. **進度可見、可續跑**：長任務不卡死；失敗要有日誌。
7. **不承諾 100%**：機器翻譯有機翻腔，社群包也會寫「不保證完美」。

## 缺點與痛點（現況常抱怨）

1. 只掃 lang → 任務／劇情／部分書本仍英文。
2. 簡中資源包當繁中用 → 用詞怪。
3. 輸出塞進 resourcepacks 根目錄 → 和任務 config 混在一起難找。
4. AI 全量翻譯 → 貴、慢、格式碼 `%s`/`§` 易壞。
5. 改遊戲原檔無備份 → 回不去。
6. pack_format 不對 → 資源包顯示不相容。
7. 翻譯工具黑窗亂跳、錯誤沒日誌 → 無法排錯。

## 不該做的事（紅線）

1. **不直接改 mods/*.jar 內容**（除非玩家明確要且有備份）。
2. **不把機翻吹成官方全漢化**。
3. **不刪玩家原任務／原資源包而不備份**。
4. **不用 AI 做分類／找檔**（成本高且不可控）；AI 只翻字串。
5. **不強制覆蓋正在執行的遊戲檔**（應提示關遊戲）。
6. **不把簡中當繁中交差**（應 OpenCC s2twp）。

## 本工具對應策略

| 社群點 | 本工具 |
|--------|--------|
| 不改 jar | 只寫 `翻譯結果/` |
| 任務 | `config/ftbquests` 輸出 |
| 合併社群包 | 參考包本機合併 |
| AI 省成本 | 本機掃＋參考包，AI 只補英文 |
| 繁中 | OpenCC 分批 + AI 後再轉 |
| 可裝 | zip + 說明 + **一鍵套用到遊戲**（先備份再複製） |
| 可排錯 | 畫面日誌 + `翻譯錯誤日誌.txt` |
| 不吹 100% | 結果目錄 `覆蓋範圍說明.txt` + 說明頁「社群期望與禁忌」+ 免責 |
| pack_format | 從遊戲既有資源包偵測，預設 15 |
