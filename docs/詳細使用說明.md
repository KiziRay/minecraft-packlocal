# 詳細使用說明（實例、資料夾、安裝與分享）

> 給第一次用的玩家。你不需要懂 jar／JSON，照著選資料夾、按按鈕即可。

## 一、什麼是「實例」／「整合包資料夾」？

**實例（Instance）＝ 你一個獨立的遊戲存放區**：裡面有那個整合包用到的 `mods`、`config`、`resourcepacks`、`saves` 等資料夾。每個整合包各自一個實例，互不干擾。

工具要你選的「整合包資料夾」就是**這個實例的根資料夾**（裡面看得到 `mods` 或 `.minecraft`／`minecraft` 的那一層）。工具會自動往裡面找 Minecraft 目錄，你不用選到最深。

## 二、各啟動器的實例資料夾在哪

| 啟動器 | 實例資料夾大概位置 |
|--------|--------------------|
| **CurseForge** | `C:\Users\你\curseforge\minecraft\Instances\<整合包名>` |
| **Modrinth App** | `C:\Users\你\AppData\Roaming\ModrinthApp\profiles\<整合包名>` |
| **Prism / MultiMC / PolyMC** | 啟動器安裝處的 `instances\<整合包名>`（實例裡通常還有一層 `.minecraft`） |
| **ATLauncher** | `ATLauncher\instances\<整合包名>` |
| **官方啟動器** | `C:\Users\你\AppData\Roaming\.minecraft`（若你用設定檔分不同版本，選對應的 game 目錄） |

**找不到？** 在啟動器裡對整合包按右鍵通常有「開啟資料夾／Open Folder」，開出來那個就是。把它整個拖進工具的「整合包資料夾」欄位即可。

## 三、該選哪個資料夾（最常見的疑問）

- **整合包資料夾**：選上面那個**實例根**。工具會自己找 `minecraft`／`.minecraft` 與 `resourcepacks`。
- **翻譯輸出位置**：選好實例後，工具會**預設把中繼檔放進自己的暫存區**（`%APPDATA%\modpack-i18n-tool\work`），**不會**在你的資料夾另外長出一個「翻譯結果」。
  - 想要一份**看得到、可自己搬**的輸出 → 按欄位下方的**「使用啟動器建議的位置」**，它會改放到實例旁邊。

## 四、翻譯 → 安裝（預設：直接覆蓋安裝）

1. 選「整合包資料夾」。
2. （選用）勾 AI 補英文；用開發者提供的免費翻譯需先 Discord 登入並加入官方伺服器，或在進階填自己的 API 金鑰。
3. 按**「開始翻譯」**。
4. **關閉 Minecraft**，按**「套用到遊戲」** → 工具會**先備份**會被覆蓋的檔，再把翻譯直接裝進遊戲的 `resourcepacks`／`config` 等。
5. 進遊戲：設定 → 語言選**「繁體中文（台灣）」**，並在資源包啟用剛裝的包。

**裝壞了或想還原？** 按**「還原上次套用」**一鍵復原（新增的刪掉、被覆蓋的從備份還原）。工具**從不改** `mods/*.jar`。

## 五、打包分享（把整包翻譯檔給別人）

想把你翻好的整包檔分享給朋友或論壇：

- 翻譯前**勾「也建立可分享的打包檔」**，翻完會請你選存放位置；或翻完後直接按**「打包成分享檔」**。
- 工具會把整個翻譯結果壓成**一個 `.zip`**（含資源包、任務、書本等）。把這個檔傳給對方即可。
- 對方拿到後：解壓，得到與工具產出相同的結構；用本工具的「套用到遊戲」或手動把 `resourcepacks` 內的 zip 放進遊戲、把 `config` 等對應覆蓋即可。

> 「一鍵上傳雲端拿分享短連結」為後續版本會加的功能；本版先做本機打包成檔，你可以用自己習慣的方式（雲端硬碟、論壇附件）分享。

## 六、常見問題

- **選了資料夾但工具說找不到 Minecraft**：你可能選到太外層或太裡層。選「裡面有 `mods` 那一層」最保險。
- **中文變方框**：切到「字體資源包」做一個含繁中的字體包並啟用；或關閉遊戲的「強制 Unicode 字型」。
- **沒有全部翻成中文**：正常。工具不宣稱 100%；圖片上的字、寫死在程式／腳本的字不會翻。詳見 [`支援範圍與免責聲明.md`](./支援範圍與免責聲明.md)。
- **遊戲開不起來**：先按「還原上次套用」排除是不是翻譯造成的；多半是整合包本身缺模組（可按「診斷開不了」看缺什麼），與翻譯無關。
