# 模組包翻譯工具使用說明

給一般 Minecraft 玩家使用。把整合包裡能讀到的遊戲文字，盡量整理成台灣用語繁體中文。圖片上的字不會翻，也不保證全部翻完。

**系統需求**：Windows 10/11 與 WebView2。翻譯與套用不需要另外安裝其他軟體。分享給其他玩家時，工具會在背景準備所需元件。

## 快速開始

1. 頂欄選「翻譯」。還沒選資料夾前，畫面只會請你選資料夾，不是當機。
2. 選你實際遊玩的整合包資料夾（需通過檢查）。每個整合包會使用專用結果位置；可在右上角「設定 → 已翻譯儲存位置」改成整合包旁或自訂資料夾。多包請勿共用同一個結果位置。
3. 在 Discord 列登入並加入官方伺服器。說明只寫在那一列。
4. 按「開始翻譯」。之後可「補充漏翻」。勾選「重新翻譯缺漏」會略過已記住的譯文。
5. 本地模型：先「同意並偵測」，確認後再「開始下載」。自訂 API 與 GPT 的費用由你自負。

重開工具時，若出現「本機已有翻譯」，可直接打開結果、再次套用或分享，不必重跑。

若偵測到 FTB 任務且有相容方案，「本包選項」才會顯示任務補充。不想用就忽略即可，一般翻譯仍會進行。

參考翻譯可選本機繁中／簡中資源包或資料夾；工具只補缺並轉成台灣用語。

## 介面

還沒選好遊戲資料夾前，翻譯頁只留選資料夾。通過檢查後才會顯示 AI、開始翻譯與右側步驟。右側「進階統計」給想看細節的人。頁尾「回報」給工具本身的問題；遊戲閃退請用診斷頁「送出診斷回報」。右上角「設定」可調整縮放（80%–170%）、音效與關閉時是否縮到背景。Ctrl＋0 重設為 100%。

## 按鈕說明

| 按鈕 | 用途 |
|---|---|
| 開始翻譯 | 第一次建立完整翻譯結果。 |
| 補充漏翻 | 只補還沒翻到的句子。 |
| 分享給其他玩家 | 做成帶密碼的自解檔，連結約一天後失效。成功後改為「複製分享連結」。 |
| 錯誤分析 | 可貼完整當機報告，或選整合包資料夾。 |
| 術語表 | 固定專有名詞譯名。 |
| 停止翻譯 | 在安全檢查點停止；已完成的部分會保留。 |
| 檢查更新 | 下載並驗證官方免安裝檔，替換後重新開啟。 |

## 已翻譯儲存位置

右上角「設定 → 已翻譯儲存位置」可選工具管理、整合包旁或自訂根目錄，並可開啟目前資料夾。本包「另外指定翻譯結果資料夾」可覆寫單次路徑。

## 字體資源包

切到「字體」分頁。這只處理中文方框，不會翻譯文字。選你有權使用的字體檔後建立資源包，在遊戲裡放到最上面，並關掉「強制使用 Unicode 字型」。

## AI 與隱私

- 登入 Discord 的說明在翻譯頁 Discord 列，此處不重複。
- 可選這台電腦上的本地模型、自訂 API 或 GPT。自訂 API 與 GPT 的第三方費用由你自負。
- 本地模型只用來翻譯遊戲文字，沒有聊天。速度快慢隨電腦而異，空間不足會擋下。檔案只放在你選的資料夾，之後可刪除。
- 金鑰與登入只存在這台電腦。送往線上服務的內容只有待翻譯字串。
- 預設會把通過檢查的匿名譯文回饋到共享庫，不含個人資料或路徑。
- 圖片上的字不處理。工具不保證全部翻完。

## 常見問題

### 遊戲出現紅字或閃退

請先「還原上一次套用」，再到「診斷」貼完整當機報告。工具本身的問題用頁尾「回報」。

### 中文變成方框（□）

這是缺字形。用「字體」分頁做成資源包，在遊戲裡置頂，並關掉「強制使用 Unicode 字型」。

### 翻譯結果沒有全部完成

覆蓋範圍會受整合包與文字來源影響。請看「覆蓋範圍說明.txt」，必要時用「補充漏翻」。寫死在程式、圖片或遊戲執行時才產生的文字可能找不到。

### 圖片裡的文字會翻嗎？

不會。

### 分享檔可以直接丟給別人嗎？

可以。對方下載後輸入密碼、選整合包資料夾即可套用。連結約一天後失效。請先在遊戲中檢查，並確認沒有私人內容。若暫時無法建立分享檔，請稍後再試。

### 備份與刪除

「套用前建立備份」預設開啟。取消後會直接覆蓋，且不能還原這次操作。備份放在翻譯結果資料夾。請自行另外備份重要存檔，並在遊戲關閉時操作。

## 支援範圍（摘要）

**會處理**：常見載入器的語言檔、任務與書本顯示文字、部分設定與資源包覆寫。支援 Minecraft 1.13 以上與年份版 26.x。更舊的版本會拒絕翻譯。

**不會處理**：圖片上的字、寫死在程式裡的字串、基岩版市集加密包、與翻譯無關的閃退或缺模組。

完整清單見 [`支援範圍與免責聲明.md`](./支援範圍與免責聲明.md)。
