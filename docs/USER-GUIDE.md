# 模組包翻譯工具使用說明

給一般 Minecraft 玩家使用的繁體中文工具。你不需要懂 jar、JSON 或資源包格式，照著畫面操作即可。

## 快速開始

1. 在「翻譯整合包」頁面選取你實際遊玩的整合包資料夾。
2. 「翻譯結果位置」預設會自動建立每個實例獨立的結果位置，完成後直接套用到正確的 Minecraft 資料夾。想另外保存結果時，勾選「另外指定翻譯結果資料夾」再輸入或選取資料夾；勾選但留白仍使用自動位置。
3. 想補上沒有繁中的英文時，勾選 AI，再選「開發者提供的 API」或「自訂 API」。開發者 API 需要登入 Discord 並加入官方伺服器。
4. 按「開始翻譯」，等待進度完成。
5. 翻譯完成會依「套用前建立備份」選項決定是否備份，再直接套用；之後可以按「再次複查翻譯」找新增或漏掉的文字。

畫面會依目前階段自動收起不需要的項目：還沒選資料夾時不會顯示輸出、AI、參考包與翻譯操作；翻譯進行中只保留停止按鈕；完成後才會顯示複查與分享。這些項目不是故障，而是避免誤按。

## 介面與主題

工具預設使用深色模式，適合長時間查看翻譯進度與日誌。按右上角的「深色／淺色」即可切換；選擇會保存在這台電腦，下次開啟會沿用，不會同步到其他裝置。介面已針對 24、27 與 32 吋螢幕放大。右上角也可以檢查更新，或按「介面 100%」重設顯示比例。按 Ctrl＋↑／↓，或按住 Ctrl 滾動滑鼠滾輪，可在 100%～150% 間調整介面大小。

如果勾選「關閉視窗時縮到背景」，按右上角關閉或 Alt+F4 時，工具會先顯示提示，再留在背景繼續工作。要完全結束工具，請取消勾選後再關閉，或使用「離開工具」。

## 翻譯整合包服務

這項服務會讀取模組語言檔，處理以下內容：

- 已有簡體中文的文字：轉成台灣繁體中文與常用台灣用語。
- 沒有繁中的英文文字：可登入 Discord 使用開發者代管 AI，也可以改用自己的 API。
- Minecraft 版本：會從遊戲實例自動偵測，也可以在畫面上手動指定。
- 語言檔中的格式佔位符：會保護 `%s`、`%1$s`、`{0}`、`§` 等內容，不符合時退回原文。
- JAR 語言檔：會讀取模組 JAR 的 `assets/<模組>/lang/*.json`／`.lang`，建立翻譯副本；原始 JAR 只讀，若勾選備份才會在套用前保留同名檔。含簽章的 JAR 會略過並寫入錯誤日誌。
- JAR 文件複查：會讀取 JAR 內可讀的文字文件，並留下 class 文字線索供複查；不會執行 JAR。
- 資源包、FTB Quests、Patchouli、OpenLoader、KubeJS 等支援的文字來源：依工具支援範圍輸出。

工具不會翻譯圖片裡的字，也不會直接寫入原始 `mods/*.jar`；翻譯副本會在套用時替換同名檔。

### 按鈕說明

| 按鈕 | 用途 |
|---|---|
| 開始翻譯 | 第一次建立完整翻譯結果。 |
| 再次複查翻譯 | 重新找新增或上次沒完成的文字，可重複使用。 |
| 翻譯完成後分享 | 只打包可安裝檔，登入 Discord 後建立 24 小時有效的短連結。 |
| 錯誤分析 | 貼上 crash report 或 latest.log，分辨翻譯問題與模組／版本問題。 |
| 術語表 | 固定模組專有名詞的翻譯，例如物品、怪物或機器名稱。 |
| 停止翻譯 | 在下一個安全檢查點停止長任務，已完成的部分會保留。 |
| 檢查更新 | 下載並驗證官方免安裝 EXE，自動替換後重新開啟；失敗時可改用瀏覽器下載。 |

### 參考翻譯

「參考翻譯（選用）」會優先使用本機找到的 CTE2 等繁中語言資料。工具目前會搜尋下載資料夾、文件、桌面，以及各磁碟的 Downloads／Download／Down／Games 淺層位置；你提供的
D:\Down\ccc\CTE2\CTE2-繁體中文翻譯-僅翻譯 會被納入搜尋。找不到時可手動選取資料夾。參考資料只補缺少的鍵，不覆蓋整合包已有的繁中，也不會改原始 JAR。

### 分享前確認

「翻譯完成後分享」不會直接上傳。先按按鈕，再勾選「我已自行檢查翻譯」與「我確認沒有私人內容」，工具才會開始上傳。R2 分享區和更新檔、翻譯記憶分開，短連結只保存 24 小時；分享頁也會提供 cloud.zeitfrei.uk 遊戲下載與 ZeitFrei 工具箱連結，適合貼到論壇或第三方平台預覽。

## 字體資源包服務

字體資源包是獨立服務，不會翻譯文字。它會把使用者選取的字體檔和 Minecraft 字體設定打包成資源包，讓遊戲文字與模組介面使用喜歡的字體。

### 建立方式

1. 切到「字體資源包」頁面（這是獨立服務，不會改變翻譯流程）。
2. 選取你有權使用的 `.ttf`、`.otf` 或 `.ttc` 字體檔。
3. 選取字體包輸出位置並設定資源包名稱。
4. 調整設定後按「建立字體資源包」。
5. 把輸出的資源包放進啟動器實例的 `resourcepacks`，再到 Minecraft 的「設定 → 資源包」啟用。

### 進階設定

| 設定 | 說明 |
|---|---|
| 字體大小 | 調整 Minecraft 字體 provider 使用的基準尺寸。 |
| 字重感 | 在 renderer 層做小幅近似調整。它不會改寫字體檔的真正筆畫。 |
| 水平位移 | 修正字體在遊戲中偏左或偏右。 |
| 垂直位移 | 修正字體在遊戲中偏上或偏下。 |
| 清晰度 | Minecraft 的 `oversample` 設定。越高通常越平滑，也可能增加資源需求。 |

如果需要真正的粗體或細體，請直接選取對應字重的字體檔，例如 Regular、Medium、SemiBold 或 Bold。工具不會重新繪製或修改 TTF/OTF/TTC 原始檔。

建立後會同時寫入 `default.json` 與 `uniform.json`，讓一般文字和 Unicode 文字都能使用。

## 輸出資料夾

「翻譯結果位置」裡的 `翻譯結果/` 通常會包含：

```text
翻譯結果/
├─ resourcepacks/
├─ config/
├─ patchouli_books/
├─ jar-translated/
├─ 翻譯工作階段.json
├─ 覆蓋範圍說明.txt
└─ 翻譯錯誤日誌.txt
```

如果你勾選了套用前備份，`翻譯套用備份_*` 也會放在這個結果資料夾。工具內的「刪除結果」會完整刪除 `翻譯結果/` 與其中備份，不會刪除你選的上層資料夾或遊戲資料夾。實際內容會依整合包使用的模組和文字來源而不同。分享檔不包含工作階段、備份、覆蓋報告、錯誤日誌或本機絕對路徑。

## AI、金鑰與隱私

- AI 是選用功能。關閉 AI 仍可做簡繁轉換、掃描、分類和資源包輸出。
- 選擇「開發者提供的 API」時，必須登入 Discord、加入 [ZeitFrei 官方伺服器](https://discord.gg/zeitfrei)，再於瀏覽器完成 Cloudflare 安全驗證。工具會在開始翻譯前引導操作，伺服器也會在每次呼叫時重新檢查；共用額度有限。
- 選擇「自訂 API」時，在自訂 API 設定填入自己的金鑰與 API 位置。這個模式不需要 Discord 驗證，費用與額度由使用者自己的服務負責。
- Discord 登入狀態只保存在本機。登出、登入過期或離開官方伺服器後，開發者 API 會停止使用。
- Cloudflare 驗證完成後取得的短效憑證只放在目前開啟的工具記憶體；重開工具或憑證過期後需要重新驗證。Turnstile Secret 不會進入桌面程式。
- API 金鑰只儲存在本機設定檔，不會寫進翻譯結果或程式預設值。
- 送往 AI 的內容只包含待翻譯字串。請自行確認你使用的 AI 服務條款。
- 不要把含有個人資料、私密伺服器資訊或不應外傳內容的字串送往第三方服務。
- AI 可能產生錯誤、過於直譯或缺少上下文的結果。遇到重要名稱請使用術語表修正。
- 為了讓大家不必重複翻同一個模組，工具預設會把**匿名**的翻譯條目（模組 id、語言鍵、原文與譯文）回饋到社群共享翻譯庫；**不含任何個人資料、路徑或身分**，只在有網路時進行、失敗即靜默略過。斷網或自備服務即不回饋。
- 共享記憶會先用「模組＋語言鍵＋原文」精確比對；同一原文只因空白或換行不同時會正規化後重用。跨模組的相似候選還會比對語境，遇到不同譯文會標記衝突並停止自動套用，不會硬覆蓋。

## 常見問題

### 遊戲出現紅字或閃退

切到「錯誤分析」，貼上 crash report 或 latest.log。工具會列出分析代碼與線索；例如 `unbound value` 通常是模組內容或版本註冊問題，不是翻譯造成。你也可以先停用資源包，必要時用「還原上一次套用」。

### 中文變成方框

切換到「字體資源包」，選擇支援繁中的字體檔並建立資源包，再到遊戲資源包選單啟用。也可以關閉「強制使用 Unicode 字型」後重新啟動遊戲。

### 翻譯結果沒有全部完成

翻譯覆蓋範圍會受到整合包版本、文字來源、AI 設定和工具支援範圍影響。請查看「覆蓋範圍說明.txt」和「翻譯錯誤日誌.txt」，必要時重複使用「再次複查翻譯」。工具不保證 100% 翻譯，寫死在程式、圖片或執行時產生的文字可能找不到。

### 圖片裡的文字會翻嗎？

不會。目前只處理遊戲文字與相關語言檔，不處理圖片 OCR。

### 為什麼有些按鈕一開始看不到？

這是流程控制。請先選實例，工具才知道 Minecraft 位置；完成翻譯後才會顯示複查與分享。AI 設定只在勾選 AI 時顯示，自訂 API 進階欄位只在選擇自訂 API 時顯示。

### 整合包更新後要重新付費翻譯嗎？

先按「再次複查翻譯」。本機翻譯記憶、參考包與匿名社群記憶會先處理完全相同的內容，只有新的或有上下文衝突的文字才需要再次送 AI。不同模組如果只是「看起來像」而不是安全匹配，工具會保留原文或交給 AI，不會冒險套錯。

### 參考包會覆蓋我原本的翻譯嗎？

不會。參考包只填補目前沒有繁中的鍵；整合包自己已有的繁中優先保留。

### 分享檔可以直接丟給別人嗎？

可以，但請先在遊戲中檢查，並確認分享檔沒有私人內容。對方開啟連結會先看到介紹頁，按下載後取得壓縮檔；解壓到相同 Minecraft 實例即可。連結 24 小時後失效。

### JAR 會被修改嗎？

原始 mods/*.jar 只讀。工具會建立可套用的翻譯副本；是否在套用前備份同名檔由玩家勾選決定。已簽章且不能安全重寫的 JAR 會略過並記錄原因。

### 備份與刪除

「套用前建立備份」預設開啟，適合第一次使用或正在測試的整合包。取消勾選後，工具會直接覆蓋目標檔案，不會建立 `翻譯套用備份_*`，也不能還原這次套用。備份會放在翻譯結果資料夾；可按「刪除全部備份」只刪除工具建立的備份，或按「刪除結果」完整刪除結果資料夾。

## 支援範圍（哪些能翻、哪些不能）

**會處理**：Forge／NeoForge／Fabric／Quilt 的語言檔；FTB Quests、Patchouli 書本、OpenLoader、KubeJS、FancyMenu、鬆散資料包的文字；Origins／Apoli 能力；以及 Better Questing／HQM／Heracles／Modonomicon 的任務／書本顯示文字。支援 Minecraft 1.13～1.21.x 與年份版 26.x。

**不會處理**：圖片上的字、寫死在 Java 程式碼或 KubeJS 腳本裡的字串、GuideME 的 Markdown 書本、被壓成 .zip 的資料包、基岩版（Bedrock）。這些屬設計紅線或本版尚未支援。

完整支援清單、版本相容與詳細免責條款見 [`支援範圍與免責聲明.md`](./支援範圍與免責聲明.md)。
