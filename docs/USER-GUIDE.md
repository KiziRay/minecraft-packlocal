# 模組包翻譯工具使用說明

給一般 Minecraft 玩家使用的繁體中文工具。你不需要懂 jar、JSON 或資源包格式，照著畫面操作即可。

本工具的目標是「能翻的玩家文字盡量都翻」，不是只翻幾個物品名稱。開啟 AI 時會分批處理大型整合包的全部候選文字；不開 AI 時仍會做本機轉換、術語表、參考包與翻譯記憶，但沒有現成譯文的英文會保留。

**系統需求**：Windows 10/11 與 **WebView2**（啟動必要）。翻譯／套用不需 Python 或其他外掛；「分享給其他玩家」需本機已裝 **NanaZip**。

## 快速開始

1. 頂欄選「翻譯」後，選取你實際遊玩的整合包／遊戲實例資料夾（需通過實例檢查：有 mods 與模組檔，以及 config／options.txt／resourcepacks 或啟動器實例特徵之一）。每個整合包會自動使用**專用結果位置**（`AppData\…\work\packs\…`），多包請勿勾「另外指定」後共用同一資料夾。
2. 按「開始翻譯」。工具固定進階解包、接續翻譯與劇情／書本優先；圖片與硬編碼英文可能仍留下，不宣稱 100%。翻譯進行中仍可切到字體／診斷分頁瀏覽、開說明或縮窗，但不可再開第二個翻譯／改路徑。
3. AI 輔助翻譯與 Discord 驗證在主頁；結果位置、**資源包名稱**（可翻譯前自訂，留空則系統產生）、版本、參考翻譯在「更多選項」。想另外保存結果時，勾選「另外指定翻譯結果資料夾」。
4. 想補上沒有繁中的英文時，勾選「啟用 AI 幫你翻譯」，再選「開發者 API」或「自訂 API」。開發者 API 需要登入 Discord 並加入官方伺服器；自訂 API 推薦 DeepSeek（便宜划算，[platform.deepseek.com](https://platform.deepseek.com)）。
5. 等待進度完成；完成後依「套用前建立備份」選項決定是否備份，再直接套用。之後可按「補充漏翻」只補仍缺。按「停止」時已完成的有效譯文仍會盡量上傳共享庫（已上傳過的不會重複灌庫）。

一鍵翻譯不再提供模式／品質選單（固定盡量完整）；補翻或修復時可勾選「重新翻譯缺漏（忽略記憶）」略過本機與共享翻譯記憶（會多用 AI）。「已達九成的模組略過」等模式僅後端保留，一般玩家不需設定。後端完整度分級：標準較快（略過 JAR 內非書本顯示 JSON）；盡量完整才翻 JAR 顯示文字與文件複查。

如果工具偵測到 FTB Quests，而且目前版本有相容的任務匯出輔助模組，「更多選項」內才會顯示「任務補充」。這不是必做設定：按「準備任務補充」後，工具只會準備一個相容版本；啟動遊戲執行畫面上的指令，回到工具按「重新翻譯」即可把匯出的任務文字一起納入。原本就安裝的輔助模組不會被工具刪除；工具自己下載的模組在翻譯完成後會自動移除，也可以提前按「清理輔助模組」。版本或載入器不相容時，這個區塊會直接略過，不會卡住主翻譯流程。

參考翻譯可選本機繁中／簡中資源包、社群漢化資料夾或 zip；也可按「嘗試下載 CFPA（對應 MC 版本）」抓公開簡中資源包（失敗可略過改本機選檔）。工具只填缺並轉台灣用語，不會把參考包上傳到共享 R2。CFPA 多為 CC BY-NC-SA，授權請自行遵守。

## 介面與主題

0.3.8 起：右側五步含「補充」；一鍵會自動補仍缺；分享為帶密碼自解 exe（密碼見下載頁）；支持開發改為維繫免費 AI。進度列現在會額外顯示目前階段的條數、等待／重試／限流／降級／取消狀態，以及 AI 批次與 token 指標；這些是即時狀態，不代表 ETA 保證。0.3.6 起：介面縮放非 100% 時改為視埠對齊，不再左右留白。0.3.5 起：翻譯中主畫面不收合，只鎖定設定（停止仍可用）；任務補充需勾選確認後才重譯；「報告」開啟執行日誌（非工作階段 json）。頁尾在各縮放比例下皆保留。0.3.4 起：首次啟動會有逐步引導（⋯ 可重播）；自動縮放開啟時 Ctrl＋滾輪／方向鍵改在游標旁提示鎖定。0.2.6 起：代管 AI 若因 Turnstile 未就緒回 503，會顯示「安全驗證尚未完成服務端設定」，不再誤報「服務端維護中」。0.2.5 起：安全驗證失敗會顯示真實原因（網路／Siteverify／金鑰／網域），不再籠統「驗證服務暫時無法使用」。0.2.4 起：修正啟動時 UI 全黑／按鈕無效（骨架蓋層＋接線中斷）。未通過遊戲資料夾實例檢查前，翻譯頁只留選資料夾引導；AI、開始翻譯與右側步驟／日誌會隱藏，通過後再展開。「支持開發」在頁尾與 AI 區塊。頂欄為品牌與三服務（翻譯／字體／診斷）；主題、縮放、更新、說明收在右上角「⋯」。完整挑戰會另寫「待補缺口摘要.txt」（樣本鍵，非完整盤點）。按 Ctrl＋↑／↓ 或 Ctrl＋滾輪可調介面大小（選單內可重設 100%；自動縮放開啟時改為鎖定提示）。

如果勾選「關閉視窗時縮到背景」，按右上角關閉或 Alt+F4 時，工具會先顯示提示，再留在背景繼續工作。要完全結束工具，請取消勾選後再關閉，或使用「離開工具」。

## 翻譯整合包服務

這項服務會讀取模組語言檔，處理以下內容：

- 已有簡體中文的文字：轉成台灣繁體中文與常用台灣用語。
- 沒有繁中的英文文字：可登入 Discord 使用開發者代管 AI，也可以改用自己的 API。
- Minecraft 版本：會從遊戲實例自動偵測，也可以在畫面上手動指定。
- 語言檔中的格式佔位符：會保護 `%s`、`%1$s`、`{0}`、`§` 等內容，不符合時退回原文。
- JAR 語言檔：會讀取模組 JAR 的 `assets/<模組>/lang/*.json`／`.lang`，建立翻譯副本；原始 JAR 只讀，若勾選備份才會在套用前保留同名檔。含簽章的 JAR 會略過並寫入錯誤日誌。
- JAR 文件複查：會讀取 JAR 內可讀的文字文件，並把可辨識的 JSON／Markdown／properties 玩家文字送入同一套翻譯流程，再建立 `jar-translated` 副本；`.class` 只留下文字線索，不會改寫程式位元碼，也不會執行 JAR。一鍵為盡量完整時才做；標準完整度會略過 JAR 內非書本顯示 JSON 以加快速度。JAR 內 Patchouli 書同樣寫入這個副本（不再套用到遊戲 `data/` 資料夾）。
- 大型文字來源：工具會把候選文字自動分成名稱、一般介面、劇情長文與超長單句幾種軌道，再分批送出；先單批暖機，再逐步提高並行。批次缺項只會重送未完成的索引，不會把整批成功結果丟掉。
- 相容降級：若你選的 AI 服務不接受 `response_format`、`max_tokens` / `max_completion_tokens` 或 `temperature`，工具會在本輪自動降級並繼續，不需要你手動重填設定。
- 舊式設定檔：部分顯示型 `config`、手冊與 ZIP 內容的 `.properties` `key=value` 文字也會嘗試處理。
- 資源包、FTB Quests、Patchouli、OpenLoader、KubeJS 等支援的文字來源：依工具支援範圍輸出；JAR 內的 JSON／Markdown／properties 顯示文字也會一起複查。

工具不會翻譯圖片裡的字，也不會直接寫入原始 `mods/*.jar`；翻譯副本會在套用時替換同名檔。要保證遊戲能玩，`id`、路徑、格式符號、事件資料與 Java 程式碼不會被當成一般文案亂改。

硬碟空間：翻譯期間只會暫時解壓一個 ZIP／JAR 來源，完成或中斷收尾時會清掉暫存；掃描快取會移除不存在的檔案並限制大小。翻譯後的 JAR 副本本身可能接近原 JAR 大小，因為它要取代遊戲使用的語言檔；若不需要複查、備份或分享，可在工具內刪除翻譯結果。一般玩家不需要 GPU，SSD 與足夠的暫存空間比硬體加速更有幫助。

### 按鈕說明

| 按鈕 | 用途 |
|---|---|
| 開始翻譯 | 第一次建立完整翻譯結果。 |
| 補充漏翻 | 只補仍缺的語言表與覆寫，已譯不重送 AI。 |
| 分享給其他玩家 | 打包帶密碼自解 exe（需本機已裝 NanaZip），登入 Discord 後建立 24 小時短連結。成功後按鈕改「複製分享連結」，再點只寫剪貼簿（網址不進日誌）。分享含資源包 zip 與 config 覆寫，不含翻譯 JAR 副本；大檔分塊上傳（軟頂約 4GB）。 |
| 錯誤分析 | 可貼完整 crash／latest，或選整合包資料夾做記錄＋mods 交叉驗證；一次只給一個主因與下一步。 |
| 術語表 | 固定模組專有名詞的翻譯，例如物品、怪物或機器名稱。 |
| 停止翻譯 | 在下一個安全檢查點停止長任務；已完成部分保留，有效譯文會上傳共享庫（已上傳過的不重複灌庫；停止掃尾限時／限量，逾時略過以免卡在 96%）。 |
| 檢查更新 | 下載並驗證官方免安裝 EXE，自動替換後重新開啟；失敗時可改用瀏覽器下載。 |

### 任務補充怎麼用

只有偵測到 FTB Quests 且有相容方案時才會出現。工具會在區塊內直接顯示要輸入的遊戲指令；你不需要自己搜尋 JAR 或猜版本。若不想使用，直接忽略即可，主流程仍會翻譯一般語言檔與能直接讀到的任務資料。若按過「準備任務補充」，但最後沒有翻譯，請按「清理輔助模組」；工具只會移除自己下載的那一個檔案。

### 參考翻譯

「參考翻譯（選用）」可手動指定本機繁中／簡中資源包、社群漢化資料夾或 zip。參考資料只補缺少的鍵，不覆蓋整合包已有的繁中，也不會改原始 JAR；簡中參考會在合併後轉成台灣用語。

### 分享前確認

「分享給其他玩家」只在本機翻譯結果內已有可安裝檔時出現。先按按鈕，再勾選「我已自行檢查翻譯」與「我確認沒有私人內容」，工具才會開始上傳。分享檔為 NanaZip 帶密碼自解 exe（密碼 `cloud.zeitfrei.uk`，下載頁也會顯示；檔名固定「模組包繁中翻譯自解檔.exe」；**分享者電腦需已安裝 NanaZip**）；`resourcepacks/` 只放 zip（頂層資料夾會先打成同名 zip）。對方執行後選擇 Minecraft 目錄即可自動套用。分享包含主資源包與 config／任務等覆寫，**不含**翻譯 JAR 副本；超過約 100MB 也會以分塊上傳（軟頂約 4GB）。成功後按鈕改成「複製分享連結」，網址只留在記憶體、**不寫進日誌**；更換遊戲資料夾或重開工具後需重新分享。R2 分享區和更新檔、翻譯記憶分開，短連結只保存 24 小時。啟用雲端 USAGE KV 後每人每日約 3 次、同時未過期約 2 個，超限會提示明天再試。跨設備重用譯文靠匿名共享庫（同模組＋語言鍵＋原文），不是整包雲端備份。

## 字體資源包服務

字體資源包是獨立服務，不會翻譯文字。它會把使用者選取的字體檔和 Minecraft 字體設定打包成資源包，讓遊戲文字與模組介面使用喜歡的字體。

### 建立方式

1. 切到「字體資源包」頁面（這是獨立服務，不會改變翻譯流程）。
2. 選取你有權使用的 `.ttf` 或 `.otf` 字體檔（不支援 `.ttc` 合集）。
3. 選取字體包輸出位置並設定資源包名稱。
4. 調整設定後按「建立字體資源包」。
5. 可手動把輸出的資源包放進啟動器實例的 `resourcepacks`，或先在翻譯頁選好整合包後勾選「建立後套用到目前整合包 resourcepacks」。若目標已有同名資源包，工具會先備份再覆蓋。

### 進階設定

| 設定 | 說明 |
|---|---|
| 字體大小 | 調整 Minecraft 字體 provider 使用的基準尺寸。 |
| 字重感 | 在 renderer 層做小幅近似調整。它不會改寫字體檔的真正筆畫。 |
| 水平位移 | 修正字體在遊戲中偏左或偏右。 |
| 垂直位移 | 修正字體在遊戲中偏上或偏下。 |
| 清晰度 | Minecraft 的 `oversample` 設定。越高通常越平滑，也可能增加資源需求。 |

如果需要真正的粗體或細體，請直接選取對應字重的字體檔，例如 Regular、Medium、SemiBold 或 Bold。工具不會重新繪製或修改 TTF/OTF 原始檔。

建立後會同時寫入 `default.json` 與 `uniform.json`，讓一般文字和 Unicode 文字都能使用。

## 輸出資料夾

「翻譯結果位置」裡的 `翻譯結果/` 通常會包含：

```text
翻譯結果/
├─ resourcepacks/          ← 主資源包（一個；遊戲內語言檔寫這裡）
├─ resourcepacks-extra/    ← 僅舊流程／非資源包 ZIP 副本（不再為 resourcepacks 複製一堆 extra zip）
├─ data/                   ← 除錯用抽出（不套用到遊戲）
├─ config/
├─ patchouli_books/
├─ jar-translated/         ← 書本／顯示文字 JAR 副本（套用進 mods）
├─ 翻譯工作階段.json
├─ 覆蓋範圍說明.txt
└─ 翻譯錯誤日誌.txt
```

右側進度儀表的分母以**本波待譯**為準；命中明細預設收合，需要時再展開。佔位符（`%s` 等）不符時會快失敗並保留英文，不反覆重試。共享術語／翻譯記憶會本機佇列後回饋（單次上傳有時間上限，避免 AI 結束後畫面假卡住）；同整合包可命中共享 glossary，跨包仍需至少兩個來源確認（雲端規則需部署 Worker 後生效）。若本機 `%APPDATA%\modpack-i18n-tool\shared_contribute_queue.json` 異常膨脹，可關閉工具後刪除該檔再重跑。

如果你勾選了套用前備份，`翻譯套用備份_*` 也會放在這個結果資料夾。工具內的「刪除結果」會完整刪除 `翻譯結果/` 與其中備份，不會刪除你選的上層資料夾或遊戲資料夾。實際內容會依整合包使用的模組和文字來源而不同。分享檔不包含工作階段、備份、覆蓋報告、錯誤日誌或本機絕對路徑。

## AI、金鑰與隱私

- AI 是選用功能。關閉 AI 仍可做簡繁轉換、掃描、分類和資源包輸出。
- 選擇「開發者提供的 API」時，必須登入 Discord、加入 [ZeitFrei 官方伺服器](https://discord.gg/zeitfrei)。代管翻譯由開發者個人提供，不是無限額度；額度用盡時代管不可用，共享庫與本機轉換仍可用。畫面會顯示**個人今日額度**與**共享本週額度**（共享池每週一 UTC 重置、上限 1000 萬）；個人預設每日 50 萬，到巴哈姆特工具介紹貼文按 GP 可將個人今日**總額度**提升至 100 萬（不必看影片；不是減少已使用量）。線上翻譯可能有錯，歡迎診斷回報。
- 選擇「自訂 API」時，選擇你取得 Key 的服務商預設，再填 Key 即可；目前內建 DeepSeek、智譜 GLM、OpenAI 與通義千問，工具會自動準備官方 Base URL 與模型，不需要手動設定網址。**推薦 DeepSeek（便宜划算）**：到 [platform.deepseek.com](https://platform.deepseek.com) 申請金鑰後選 DeepSeek 填入即可（工具使用官方 `deepseek-v4-flash` 並關閉思考模式，與 [DeepSeek API 文件](https://api-docs.deepseek.com/zh-cn/) 一致）。儲存後會自動測試金鑰，也可按「測試金鑰」；開始翻譯前（自訂＋開 AI）也會先探測，失敗不會白掃一輪。這個模式不需要 Discord 驗證，費用與額度由使用者自己的服務負責。代管額度用盡或自訂失敗時，同樣建議改用自訂 DeepSeek。
- 如果使用尚未內建的 OpenAI 相容服務，才選「其他 OpenAI 相容服務」，再填 Base URL 與模型名稱。服務商不能只靠 Key 自動猜出來，因為不同平台可能使用相同格式；工具只接受安全的 HTTPS 服務。
- Key 輸入後只會顯示固定數量的 `#`，儲存後也不會回傳 Key 內容或實際長度。
- 補譯日誌與覆蓋說明現在會額外顯示 AI token 用量，例如 prompt cache 命中／未命中與 completion token；這些只用來幫你判斷本輪是否有吃到快取，不會上傳你的本機資料夾內容。
- Discord 登入狀態只保存在本機。登出、登入過期或離開官方伺服器後，開發者 API 會停止使用。

## 常見問題

### 遊戲出現紅字或閃退

切到「錯誤分析」，優先貼上完整 crash report；也可以選整合包／實例資料夾。閃退請先「還原上一次套用」。診斷頁可送出多類回報（需 Discord；資料 3 天刪除，開發者只收到連結）。若懷疑共享庫，補翻時勾選「重新翻譯缺漏（略過共享庫查找）」再重跑——只停查找，仍會貢獻。工具每次只給一個主因。只貼 `Process exited with code: -1` 通常只有結果沒有原因，請補上 `Description:`、`Caused by:` 和錯誤堆疊。像 `unbound value` 通常是模組內容或版本註冊問題，不是翻譯造成。若出現大量 `Unknown required criterion` 或 `FrameType`／`DisplayInfo` 空值 NPE，多半是進度 JSON 機制欄被舊版改壞：請還原後用新版重跑。

### 中文變成方框（□）

這是**缺字形**，不是編碼壞掉。切換到「字體資源包」，選支援繁中的字體檔建立資源包；在遊戲資源包選單**啟用並置頂**（高於 GUI／材質包），並關閉「強制使用 Unicode 字型」後重開。

### 中文變成 Ã、å、æ 怪碼

這是**編碼／覆寫**問題，不是字體。請「還原上次套用」後用本工具重產再套用；並檢查是否有第三方語言包蓋過。工具寫出語言檔一律 UTF-8（不做 Latin-1 重寫）。

### 翻譯結果沒有全部完成

翻譯覆蓋範圍會受到整合包版本、文字來源、AI 設定和工具支援範圍影響。請查看「覆蓋範圍說明.txt」和「翻譯錯誤日誌.txt」，必要時重複使用「補充漏翻」。工具不保證 100% 翻譯，寫死在程式、圖片或執行時產生的文字可能找不到。

### 圖片裡的文字會翻嗎？

不會。目前只處理遊戲文字與相關語言檔，不處理圖片 OCR。

### 為什麼有些按鈕一開始看不到？

這是流程控制。請先選實例，工具才知道 Minecraft 位置；完成翻譯後才會顯示複查與分享。AI 設定只在勾選 AI 時顯示；自訂 API 先選服務商預設，只有選「其他」時才顯示 Base URL 與模型欄位。

### 為什麼沒有看到任務補充？

任務補充只服務 FTB Quests，而且要能確認 Minecraft 版本與載入器。Fabric、未知版本、沒有相容模組版本，或整合包沒有 FTB Quests 時，工具會隱藏這個區塊並繼續翻譯；這不是錯誤。若你已經自行安裝相容的輔助模組，工具會直接顯示指令，但不會替你刪除它。

### 整合包更新後要重新付費翻譯嗎？

先按「補充漏翻」。本機翻譯記憶、參考包與匿名社群記憶會先處理完全相同的內容，只有新的或有上下文衝突的文字才需要再次送 AI。不同模組如果只是「看起來像」而不是安全匹配，工具會保留原文或交給 AI，不會冒險套錯。

### 參考包會覆蓋我原本的翻譯嗎？

不會。參考包只填補目前沒有繁中的鍵；整合包自己已有的繁中優先保留。

### 分享檔可以直接丟給別人嗎？

可以，但請先在遊戲中檢查，並確認分享檔沒有私人內容。對方開啟連結會先看到介紹頁（含解壓密碼與選目錄說明），下載自解 exe 後執行、輸入密碼、選擇 Minecraft 目錄即可自動套用。連結 24 小時後失效。成功分享後請用「複製分享連結」再貼給對方，工具日誌不會留下網址。

### JAR 會被修改嗎？

原始 mods/*.jar 只讀。工具會建立可套用的翻譯副本；是否在套用前備份同名檔由玩家勾選決定。已簽章且不能安全重寫的 JAR 會略過並記錄原因。

### 備份與刪除

「套用前建立備份」預設開啟，適合第一次使用或正在測試的整合包。取消勾選後，工具會直接覆蓋目標檔案，不會建立 `翻譯套用備份_*`，也不能還原這次套用。備份會放在翻譯結果資料夾。再次翻譯同一個整合包、同一個套用位置時，工具會檢查既有備份的實例路徑、套用清單與備份檔案是否完整；符合時沿用原備份，不再建立重複資料夾。若這次多了尚未備份的新檔案，才會建立新的備份。可按「刪除全部備份」只刪除工具建立的備份，或按「刪除結果」完整刪除結果資料夾。

## 支援範圍（哪些能翻、哪些不能）

**會處理**：Forge／NeoForge／Fabric／Quilt 的語言檔；FTB Quests、Patchouli 書本、OpenLoader、KubeJS、FancyMenu（只翻選單按鈕／說明等顯示文，不改錨點等結構）、鬆散與 ZIP 資料包的文字；Origins／Apoli 能力；Better Questing／HQM／Heracles／Modonomicon 任務／書本顯示文字；JAR 內 `data/*/patchouli_books` 與 Citadel `assets/*/book/`（寫入 `jar-translated` 副本）；GuideME／自訂手冊的 Markdown 可讀行。支援 Minecraft **1.13～1.21.x** 與年份版 **26.x**。**1.12.2 以下禁止翻譯**（工具會拒絕開工）。

若舊版曾把 FancyMenu 主選單弄亂（大塊面板蓋住按鈕），請用「還原上次套用」或從 `翻譯套用備份_*\config\fancymenu` 覆蓋回遊戲，再用新版重翻。歡迎頁標題若做成圖片，工具不會翻圖上的字；按鈕／說明等文字欄會翻。

**不會處理**：圖片上的字、寫死在 Java 程式碼裡的字串、沒有使用明確顯示 API 的任意腳本字串、特殊或動態生成的 Markdown 結構、**基岩版市集加密包**（合規下終端玩家通常讀不到明文 lang；作者提供明文／授權包才可能另做 overlay，本工具**不做破解**）。KubeJS 只會處理 `Text.of`／`Component.literal`／`text.literal`，不會解析或改寫腳本邏輯。

完整支援清單、版本相容與詳細免責條款見 [`支援範圍與免責聲明.md`](./支援範圍與免責聲明.md)。JAR 裡寫死在 `.class` 的文字只會列為線索，不會自動改寫；這是為了避免翻譯後遊戲無法啟動。
