# Prominence II 回歸語料（去識別化）

## 這是什麼

以 2026-09-03 一次真實的 Prominence II: Hasturian Era 翻譯執行結果為來源，
整理成的**去識別化**回歸語料。用途是把總規劃 §4.1 的 P0-03（非顯示型字串進 AI 與資料庫）
與相關品質缺陷，從「診斷紀錄裡的一段描述」變成**可重跑的測試輸入**。

原始執行結果的統計（`覆蓋範圍說明.txt`，本輪實地讀取）：

| 觀察 | 數值 |
|---|---|
| 台灣可玩覆蓋率 | 約 38.4% |
| 共享庫查詢／命中 | 33,233 ／ 32,152 |
| AI 實際翻譯 | 16 條（免 AI 比例約 99%） |
| 品質未過略過 | 238 句（still_english=1／mixed_fragment=115／same_as_source=122） |
| 品質暫緩 | 240 條 |
| 佔位符退回原文 | 955 條中退回 27 條；另 13 條因不符退回 |
| 待貢獻佇列 | 8,694 條暫存；**佇列已達上限，丟棄最舊 20 條** |
| 簽章 JAR | 3 個略過 |
| 仍待補 | 908 條 |

## 去識別化規則

- 不含 API key、Discord token、access token。
- 不含使用者名稱與絕對路徑；來源位置一律相對化為 `<pack>/…` 形式。
- 只保留觸發判斷所需的結構與字面樣態；整合包的完整文案不進本語料。
- 模組名稱與語言 key 屬於公開發行的模組內容，保留原樣才有回歸價值。

## 檔案

- `candidates.jsonl` — 每行一個候選，含來源類型、key、文字與**期望分類**。

`expected` 的三個值對應總規劃 §5.1 的 Eligibility：

| 值 | 意義 |
|---|---|
| `Keep` | 本來就不該翻。送進 AI 即為缺陷（P0-03）。 |
| `Translate` | 正常遊戲文案，應該翻。 |
| `Review` | 無法自動判定，需人工確認；不得擅自翻。 |

## Phase 邊界

**Phase 0 只建立語料並驗證它不含機密**，不實作分類器。
依 `expected` 逐條驗證分類結果是 Phase 2 的工作（總規劃 §6 Phase 2 驗收）。
