支援 .ttf／.otf（拒 TTC）。建立後請在遊戲資源包列表置頂，並關閉 Force Unicode。

          詳細說明
          
    
            
    會做：掃描模組整合包裡看得到的文字，翻成繁體中文，建立翻譯結果並套用到遊戲。需要時會把翻好的模組檔放進遊戲，覆蓋前依你的選擇先備份。
    
            
    不做：不處理圖片上的字，不保證全部翻完，也不替你確認第三方翻譯或分享的授權。
    
            
    你的電腦：翻譯結果、備份、API 金鑰、ChatGPT 登入資料都存在這台電腦。
    
            
    線上功能：共享庫免登入就能查詢與分享。用 AI 翻之前要登入 Discord 並加入官方伺服器；自訂 API 與 ChatGPT 用的是你自己的額度，本地模型在這台電腦執行。
    
            
    遇到閃退：先按主畫面的「移除翻譯」，再用頁尾「問題回報」告訴我們。
