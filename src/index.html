PLAYER GUIDE / v0.1.2

模組包翻譯工具

給普通玩家使用的繁體中文工具。你不需要理解 jar、JSON 或資源包格式，只要照著頁面上的步驟操作。

介面太小或太大？按 Ctrl＋↑／↓，或按住 Ctrl 滾動滑鼠滾輪調整；點右上角的「介面 100%」可重設。

翻譯整合包

這項服務會讀取模組整合包內的語言檔、FTB 任務、Patchouli 書本、鬆散或 ZIP 資料包、JAR 內書本，以及 KubeJS 明確的顯示 API 字串。簡體中文會轉成台灣用語，沒有繁中的英文才會進入補翻流程。使用 AI 時，工具只會把需要翻譯的文字送出，其餘掃描、分類、格式保護與打包都在本機完成。開頭先選完整度（先翻能玩的／標準／盡量完整），再選資料夾。

  1. 1

    選「這次要翻多深」，再選取你實際遊玩的整合包資料夾，工具會嘗試偵測 Minecraft 版本。

  2. 2

    「翻譯結果位置」預設自動建立；想另外保存結果時，在「更多選項」勾選並輸入或選取資料夾，留白會回到自動位置。

  3. 3

    選擇翻譯模式與品質：接續適合更新、九成略過適合已翻過的大包、重新翻譯適合更換 AI 譯法；品質可選介面優先、一般或劇情與書本優先。

  4. 4

    需要補英文時勾選 AI；可使用代管服務，也可以在自訂 API 選擇服務商預設後只填 Key，Key 會以 `#` 顯示。

  5. 5

    先決定是否勾選「套用前建立備份」，翻譯完成後會直接套用到遊戲；再次翻譯同一個整合包時，工具會先尋找相同位置且內容完整的備份。

FTB 任務補充是選用的。只有偵測到 FTB Quests 且有相容版本時才會出現；工具會顯示指令，完成翻譯後自動清理自己下載的輔助模組。

Minecraft 版本

工具會從遊戲實例設定自動偵測版本，也可以在翻譯頁手動指定。這會用來產生對應的資源包格式，補翻與修復工作階段也會沿用同一版本。

按鈕對照

開始翻譯第一次建立完整翻譯結果。
補翻工作階段上次中斷、或新增文字後只補還沒完成的部分。
翻譯完成後分享只分享可安裝檔，建立 24 小時有效的短連結。
錯誤分析優先貼完整 crash report，也支援 latest.log／debug.log；顯示證據、可疑模組與下一步。
術語表指定模組專有名詞的固定譯名，例如物品、怪物或機器名稱。

字體資源包

字體資源包是獨立服務，不會翻譯文字。它會把你選的 TTF／OTF 字體檔與 Minecraft 字體設定打包成資源包，協助模組介面與遊戲文字使用你喜歡的字體。若已在翻譯頁選好整合包，可勾選建立後直接套用到目前實例 resourcepacks；同名資源包會先備份。

  • 字體大小：調整 Minecraft renderer 使用的基準尺寸。
  • 字重感：做小幅的 renderer 層近似；不會改寫字體檔的真正筆畫。
  • 水平／垂直位移：修正字體在遊戲裡偏左、偏右、偏上或偏下。
  • 清晰度：調整 oversample。越高通常越平滑，也可能增加資源需求。
想要真正的粗體？請選用 Regular、Medium、SemiBold 或 Bold 等對應字重的字體檔。工具不會修改或重新繪製字體。

輸出與套用

翻譯完成會直接套用到正確的 Minecraft 資料夾；「套用前建立備份」勾選時，工具會把備份放在「翻譯結果」資料夾。再次翻譯同一個整合包與同一個套用位置時，只要既有備份涵蓋這次要覆蓋的檔案，就會直接沿用，不會再複製一份；如果出現新的、尚未備份的目標檔案，工具才會建立新的備份。未勾選時不會建立備份，也不能用「還原上一次套用」回復這次操作。分享檔只包含可安裝內容，不會帶出工作路徑、備份或工作階段紀錄。

套用前請關閉 Minecraft。你可以在錯誤分析頁還原最近一次備份、刪除全部備份，或回到翻譯頁完整刪除結果資料夾。

AI、金鑰與隱私

AI 是選用功能。關閉 AI 仍可以處理既有中文、簡繁轉換與資源包輸出。開發者代管 API 額度有限，使用前必須通過 Discord 會員資格與 Cloudflare 安全驗證；驗證會在服務端再次執行，舊版工具不能略過。你也可以改用自己的 Key；在自訂 API 選擇服務商預設即可，不需要手動填 Base URL。

API Key 只儲存在本機設定檔，輸入與已儲存狀態都只顯示固定數量的 `#`，不會寫進翻譯結果或程式預設值。送往 AI 的內容只包含待翻譯字串與必要的通用語境。請自行確認服務條款，不要送出個人資料或私密伺服器資訊。

常見問題

遊戲出現紅字或閃退怎麼辦？先到「錯誤分析」貼完整 crash report。只貼退出碼 -1 不夠，請保留 Description、Caused by 與堆疊。工具會把遊戲退出碼和真正錯誤分開顯示。

工具說證據不足怎麼辦？重新產生一次錯誤，再同時提供 crash-reports/*.txt、logs/latest.log 和 logs/debug.log。AllTheLeaks、ModernUI、GC 或關閉遊戲的最後幾行通常只是背景訊息，不一定是根因。

中文字變成方框怎麼辦？使用字體資源包，選擇支援繁中的字體檔，再到遊戲資源包選單啟用。

圖片裡的字會翻譯嗎？不會。本工具目前只處理遊戲文字與相關語言檔。

翻譯一定完美嗎？不一定。模組上下文可能不足，請在遊戲裡檢查結果，並用術語表固定重要名稱。

免責說明

本工具由 ZeitFrei 以方便玩家整理模組包文字為目的提供。翻譯結果可能因模組版本、原文上下文、第三方 AI 服務或字體檔品質而有錯誤、不完整或不符合個人偏好的情況。

使用者應自行確認模組整合包、字體檔、翻譯內容及第三方服務的授權與使用條款。請不要使用你沒有權利散布的字體或內容。

本工具不保證遊戲一定能啟動、不保證翻譯完整、不負責模組本身的錯誤、存檔損壞、版本衝突、第三方 API 費用或任何因使用輸出結果造成的直接或間接損失。套用前請備份整合包與存檔。

按鈕何時出現

工具會依目前階段隱藏不能用或不需要的按鈕：尚未選實例時只顯示選取資料夾；翻譯進行中只保留停止；完成後才顯示再次複查、分享與開啟輸出。錯誤分析頁的還原與刪除備份只有在偵測到工具建立的備份時才出現；翻譯頁的「刪除結果」會刪除工具建立的整個「翻譯結果」資料夾。AI 設定只在勾選 AI 時出現，自訂 API 欄位在選擇自訂 API 後會直接展開。

分享與參考翻譯

參考翻譯會優先使用本機找到的 CTE2、CFPA、繁中／簡中資料夾或 zip，只補缺少的語言鍵，不覆蓋原本已有的繁中；簡中參考會轉成台灣用語，且不會上傳到共享 R2。分享不會按一下就上傳：請先檢查遊戲，再勾選兩項確認。分享檔會放到獨立 R2，連結保留 24 小時；分享頁含 cloud.zeitfrei.uk 遊戲下載與 ZeitFrei 工具箱連結，也能被論壇等第三方平台讀取預覽。

更新或重複翻譯時，工具會先比對本機與匿名社群翻譯記憶。完全相同或只是空白不同的文字可以重用；相似但上下文不一致的文字不會硬套，發現不同譯文會標記衝突。
