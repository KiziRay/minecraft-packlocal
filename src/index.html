PLAYER GUIDE / v0.2.1

模組包翻譯工具

給普通玩家使用的繁體中文工具。你不需要理解 jar、JSON 或資源包格式，只要照著頁面上的步驟操作。

介面太小或太大？視窗可自由縮放，布局會依寬高重排。也可按 Ctrl＋↑／↓ 或 Ctrl＋滾輪調介面縮放；在「⋯」選單可重設 100%。

翻譯整合包

頂欄切到「翻譯」。先選完整度，再選遊戲資料夾並按「開始翻譯」。進階設定（結果位置、AI、參考包）在選好資料夾後，按「更多選項」從右側抽屜調整。百分比為估計，不保證達標。

  1. 1

    選完整度三卡之一，再選取整合包資料夾。

  2. 2

    需要時按「更多選項」調整結果位置、版本、AI 與參考翻譯。

  3. 3

    按「開始翻譯」；進度與日誌在右側執行面板。

Minecraft 版本

工具會從遊戲實例設定自動偵測版本，也可以在更多選項手動指定。

按鈕對照

開始翻譯第一次建立完整翻譯結果。
補翻工作階段上次中斷、或新增文字後只補還沒完成的部分。
翻譯完成後分享只分享可安裝檔，建立 24 小時有效的短連結。
錯誤分析優先貼完整 crash report。
術語表指定模組專有名詞的固定譯名。

字體資源包

頂欄切到「字體」。獨立服務，不會翻譯文字。支援 TTF／OTF，拒 TTC。

輸出與套用

翻譯完成會直接套用；勾選備份時放在「翻譯結果」。套用前請關閉 Minecraft。

AI、金鑰與隱私

AI 是選用功能。代管 API 需 Discord 與 Cloudflare 驗證；也可自備 Key。Key 只存本機。

常見問題

遊戲紅字或閃退？到「診斷」貼完整 crash report。

圖片裡的字會翻嗎？不會。

免責說明

本工具由 ZeitFrei 提供。翻譯結果可能不完整；請自行確認授權與備份存檔。

按鈕何時出現

未選實例時只顯示選資料夾；「更多選項」在選好資料夾後才出現。翻譯進行中只保留停止。

分享與參考翻譯

分享需兩項確認；參考包只填缺，不上傳共享 R2。
