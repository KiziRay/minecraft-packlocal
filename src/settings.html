使用說明

  1. 在主畫面按「選擇遊戲資料夾」，選你實際在玩的模組整合包（裡面要有 mods 資料夾）。
  2. 選好後，主畫面會用一句話說明現況，並只給一顆要按的按鈕。
  3. 用 AI 翻時可選本地模型、ChatGPT 或自訂 API。開始前會先試翻一小段，確認連得上。
  4. 按「開始翻譯」，右側顯示進度。翻好會套用到遊戲，包含放入翻好的模組檔並把遊戲語言改成繁體中文；被換掉的原檔要不要先備份，照「資料與備份」的設定。
  5. 同一台電腦翻過的模組整合包會被記住，下次選同一個資料夾，不用重翻就能套用到遊戲或分享給朋友。
  6. 想拿掉翻譯，按主畫面遊戲資料夾那一區的「移除翻譯」。
  7. 中文字變成方框時，到主畫面的「字體工具」分頁做字體資源包。

免責說明

  • 這是翻譯輔助工具。AI、翻譯記憶與共享庫都可能翻錯或翻不完整，重要內容請自己再確認。
  • 圖片上的字、寫死在程式裡的字翻不到，這是技術限制，不是故障。
  • 自訂 API 與 ChatGPT 用的是你自己的帳號與額度，費用由你負擔。
  • 本地模型的速度與穩定度看你這台電腦，不保證每台都跑得動。
  • 套用前要不要備份照你的選擇做；不論選哪個，都建議你自己也留一份模組整合包與存檔。

遇到問題

請按主畫面最下方的「問題回報」，送出前看得到會附上哪些資料。畫面或翻譯怪怪的，請先別刪翻譯結果，方便找出是哪一步出錯。
